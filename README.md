# Pong — tvimogame

Классический Pong на **React 19 + Vite + Bootstrap 5** в едином визуальном стиле
платформы tvimogame. Тёмная неоновая тема, стеклянные панели, glow-эффекты,
анимированный фон. Три режима (Classic / Blitz / Survival), AI с человеческой
реакцией, бонусы, комбо и рекорды в localStorage.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

Продакшен-сборка и предпросмотр:

```bash
npm run build
npm run preview    # http://localhost:4173
```

## Тесты

End-to-end тесты на Playwright (15 сценариев: загрузка, управление, физика мяча,
отражения, счёт, пауза, победа/поражение, бонусы, рекорды в localStorage):

```bash
npx playwright install chromium   # один раз
npm run test:e2e
```

Линтер: `npm run lint`.

## Управление

| Клавиша        | Действие              |
| -------------- | --------------------- |
| `W` / `↑`     | ракетка вверх         |
| `S` / `↓`     | ракетка вниз          |
| `Space`       | пауза / продолжить    |
| `R`           | заново                |

На мобильных — touch: ведите пальцем по левой половине поля.

## Механики

- **Classic** — до 10 очков
- **Blitz** — 90 секунд, в последние 20 с мяч ускоряется
- **Survival** — против AI, цель — продержаться как можно дольше; каждые 20 с
  мяч быстрее и AI точнее; один пропущенный мяч — конец
- **AI** — задержка реакции 80–220 мс и погрешность попадания (Easy / Normal / Hard)
- **Бонусы** (переключаются, по умолчанию вкл.): большая ракетка, маленькая
  ракетка соперника, ускорение, замедление и редкий Multi Ball
- **Комбо** — серия ударов подряд; flash на ×10 и ×20
- Угол отражения зависит от места удара и движения ракетки (до ±60°)
- Скорость мяча +4% за каждый удар (до 850 px/s), swept-коллизии без «пролёта»
- Звуки генерируются через Web Audio API (переключатель 🔊/🔇, сохраняется)
- Рекорды: `pong_classic_best`, `pong_blitz_best`, `pong_survival_best`, `pong_combo_best`

## Структура

```
src/
  game/pong.js          # чистая игровая логика (физика, AI, бонусы, счёт — без React)
  game/audio.js         # Web Audio API звуки
  hooks/usePong.js      # игровой цикл (requestAnimationFrame), клавиатура, touch, рекорды
  components/
    GameField.jsx       # поле, разметка, счёт, ракетки, мяч, trail, бонусы, эффекты
    GamePanel.jsx       # панель статистики и управления
    Pong.jsx            # композиция + оверлеи (старт/пауза/голы/результат)
    Header.jsx          # шапка tvimogame
    Footer.jsx          # футер tvimogame
e2e/pong.spec.js        # Playwright E2E
```
